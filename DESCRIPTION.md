# Project description

## The question

A retailer can report revenue and order counts, but those totals do not explain which customers are likely to return, which valuable relationships are weakening, or where the next retention campaign should focus.

This project turns transaction history into a practical customer plan. It combines RFM segmentation, customer cohorts, repeat-purchase timing, value concentration, and a short-horizon repeat-purchase ranking. The final dashboard is organised as a story: find the customers who create value, see where repeat purchasing weakens, then test what a retention action could cost.

## What makes it useful

- **Customer-first analysis:** the unit of analysis changes from transaction lines to customer relationships.
- **Retention over time:** cohort tables show the share of each customer group that returns in later months.
- **Value concentration:** a Pareto view shows how dependent the business is on a small set of customers.
- **Next-90-day repeat ranking:** a simple, time-bounded model ranks customers by observed likelihood to buy again within a 90-day window. It is evaluated on a held-out set and is not presented as a lifetime-value prediction.
- **Action economics:** a small scenario planner lets the reader change outreach cost, contact rate, conversion assumption, average order value and contribution margin.
- **Honest value definitions:** historic purchase value is reported separately from profit. The source does not include acquisition cost, service cost or product margin, so true profit and fully predictive CLV cannot be measured directly.

## Intended audience

Hiring managers for data analytics, business intelligence, customer analytics, CRM analytics and commercial strategy roles.
