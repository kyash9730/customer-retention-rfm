# Generated outputs

Run `python run_project.py --source demo` to recreate these files from the included synthetic data. Run `python run_project.py --source real --download` to rebuild them from the UCI source workbook.

The standalone `dashboard.html`, aggregate `segment_summary.csv`, `cohort_retention.csv`, `repeat_model_deciles.csv`, `metrics.json`, chart images and PDF report are suitable for reviewing the run. Customer-level tables and the SQLite database are kept locally and ignored by Git because they are generated analysis data.
